# FocusFlow – אפליקציית ריכוז לאייפון

אפליקציית SwiftUI פשוטה בסגנון Pomodoro עם:

- טיימר פוקוס + הפסקה
- שליטה: התחל/עצור, דילוג, איפוס
- סטטיסטיקות יומיות (כמות סשנים + שעות פוקוס)
- היסטוריית סשנים אחרונים
- מסך הגדרות לשינוי אורכי פוקוס/הפסקה

## איך להריץ

1. פתח Xcode ויצור פרויקט iOS חדש מסוג **App** עם SwiftUI.
2. תן לפרויקט את השם `FocusFlow`.
3. החלף את קבצי ברירת המחדל בקבצים מתוך תיקיית `FocusApp/`.
4. הרץ על סימולטור iPhone או מכשיר אמיתי.

> שים לב: מאחר שהסביבה כאן אינה macOS עם Xcode, לא ניתן לבצע בנייה מלאה מקומית בתוך הקונטיינר.
